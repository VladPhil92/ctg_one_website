# Nvet Care homepage v5

This phase replaces the previous public `/nvetcareapp` composition with an image-led, responsive homepage that makes the visual redesign immediately visible above the fold.

## Goals
- Use the verified Nvet Care palette and Poppins hierarchy.
- Make photography and product UI visible in the hero and first scroll.
- Reduce visual density and repeated messaging.
- Preserve clear mobile conversion through the existing persistent action bar.
- Keep Cartagena coverage truthful and avoid invented neighborhood coverage.
- Reuse only repository-backed assets so production does not ship broken image references.

## Main visual structure
1. Immersive Nvet hero with at-home care photography and phone UI.
2. Six service cards with stronger hierarchy.
3. At-home care narrative using repository photography.
4. Three-step flow.
5. Dark product section with request and tracking UI.
6. Consolidated trust layer.
7. Cartagena coverage block using Nvet network pattern.
8. Focused final CTA.
